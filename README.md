# i.thie softworks – Homepage

Statische Label-Seite. Kein Build, keine Cookies, kein Tracking. CSS und Schrift stehen inline im HTML, separat liegen nur Bilder. Deploy per GitHub Actions bei jedem Push auf `main` ([deploy.yml](.github/workflows/deploy.yml)).

| Datei | Inhalt |
| --- | --- |
| `index.html` | Startseite: Logo, Spiele, Kanäle |
| `impressum.html` | Impressum + Datenschutz (gilt auch für YouTube und Instagram) |
| `assets/logo.svg` | Logo (Ringplanet), dazu `logo-white.svg` / `logo-black.svg` einfarbig |
| `assets/profile-800.png` | Profilbild für YouTube / Instagram |
| `assets/wordmark-dark.png` / `wordmark-light.png` | Logo + Schriftzug, 1600 × 400 |
| `assets/favicon.png` / `apple-touch-icon.png` | Icons |
